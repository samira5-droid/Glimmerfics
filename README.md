# Glimmerfics — Hogwarts Legacy

An interactive English-language Hogwarts Legacy story for Samira Wellington, preserving the choice-driven format of the source story and continuing from the existing narrative state.

## Features

- Ravenclaw fifth-year protagonist: Samira Wellington
- Numbered choices plus free-text choices
- Persistent relationship state for Sebastian, Ominis, and Anne
- Hogwarts-inspired dark visual design
- Seamless continuation from the existing story endpoint
- Ready for GitHub Pages

## Run locally

Open `index.html` in a browser. No build step is required.

## Publish with GitHub Pages

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **GitHub Actions**.
4. Run the Pages workflow.

The site is entirely client-side and uses browser `localStorage` for story progress.
